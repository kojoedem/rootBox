🛡️ rootBox Containment & Safety Protocols

1. At-Rest Disarming (XOR 0x5A): All binaries stored on disk in storage/ are bitwise XOR obfuscated. If accidental double-clicking occurs on the host, the file cannot execute as an active payload.

2. File Permissions (0600): Files in the quarantine directory are saved with owner-only read/write privileges, stripping executable flags.

3. Safe HTTP Attachment Headers: When downloading raw binaries, responses enforce X-Content-Type-Options: nosniff and force a .bin extension to prevent browser rendering or automatic execution.

4. Shannon Entropy Analysis: Entropy values near 8.0 signal heavy encryption, packing, or compression commonly used by modern malware families.
